# Advanced Deep Learning with Pytorch

Projects that I have built for learning the math and intuition behind several different deep learning concepts in PyTorch. The projects in this learning repo include CNNs, RNNs, LSTMs, Autoencoders, VAEs, VQ-VAEs, GANs, Faster R-CNN, YOLO-V1, SSD, Transformers, Vision Transformers, Latent Diffusion, Conditioned Latent Diffusion, LoRA, reinforcement learning, and more.
